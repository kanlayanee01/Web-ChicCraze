# ChicCraze

เว็บไซต์ร้านค้าแฟชั่นออนไลน์แบบสแตติก พัฒนาด้วย HTML และ CSS เป็นส่วนหนึ่งของ Workshop 5 “การพัฒนาสแตติกเว็บด้วย HTML และ CSS” วิชา CSD3202 การพัฒนาเว็บแอปพลิเคชัน

- **สาขาวิชา:** วิทยาการคอมพิวเตอร์และนวัตกรรมข้อมูล คณะวิทยาศาสตร์และเทคโนโลยี มหาวิทยาลัยราชภัฏสวนสุนันทา

## วัตถุประสงค์

- ให้ลูกค้าเลือกซื้อสินค้าได้ครบจบในเว็บเดียว
- ให้ลูกค้าเลือกซื้อสินค้าได้ตลอด 24 ชั่วโมง
- ค้นหาสินค้าได้รวดเร็วผ่านเมนูและหมวดหมู่

## กลุ่มเป้าหมาย

- ลูกค้าที่ชอบซื้อของออนไลน์
- ลูกค้าที่สนใจแฟชั่นใหม่ ๆ ทันกระแส
- ลูกค้าที่ต้องการหาสไตล์การแต่งตัว

## ฟีเจอร์หลัก

- หน้าแรก (Landing page) แบบภาพพื้นหลังเต็มจอ พร้อมปุ่ม “เลือกชมสินค้า”
- แถบเมนูด้านบน (top bar) แบบ fixed สำหรับสลับหมวดหลัก 5 หมวด
- แถบเมนูด้านซ้าย (sidebar) สำหรับเลือกหมวดย่อย และปุ่มกลับหน้าหลัก
- แสดงสินค้าแบบ CSS Grid พร้อมรูปและราคา
- รองรับหน้าจอหลายขนาด (Responsive) ด้วย media queries ที่ 1024px, 768px และ 480px

## วิธีใช้งาน

1. ดาวน์โหลดหรือ clone โปรเจกต์นี้
2. เปิดไฟล์ `ChicCraze.html` ด้วยเว็บเบราว์เซอร์ (Chrome, Edge, Firefox ฯลฯ)
3. กดปุ่ม “เลือกชมสินค้า” เพื่อเข้าสู่หน้าสินค้า แล้วใช้เมนูด้านบนและด้านซ้ายเพื่อเปลี่ยนหมวด

> ไม่ต้องติดตั้งโปรแกรมเพิ่ม แต่ต้องต่ออินเทอร์เน็ตเพื่อให้รูปสินค้าแสดงผล เพราะรูปสินค้าโหลดจากลิงก์ภายนอก

## Style Guide

| องค์ประกอบ | ค่า |
|---|---|
| สีหลัก (Top bar / Hover) | `#f8500a` |
| สีรอง (Sidebar) | `#0f2238`, `#1f2f40` |
| ปุ่มหน้าแรก | `#ff7700` (hover `#777777`) |
| การ์ดสินค้า | พื้น `rgb(170,170,170)` กรอบ `5px solid gray` |
| ฟอนต์ | `sans-serif` |

### Responsive

| ความกว้างจอ | จำนวนคอลัมน์สินค้า | Sidebar |
|---|---|---|
| > 1024px | 4 | กว้าง 20% |
| ≤ 1024px | 3 | กว้าง 25% |
| ≤ 768px | 2 | กว้าง 30% |
| ≤ 480px | 1 | ย้ายขึ้นด้านบน เต็มความกว้าง |

## เทคโนโลยีที่ใช้
